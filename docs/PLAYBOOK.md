# Плейбук: nightcity (по образцу rainroom)
- Vite + Three.js, base `/nightcity/`, деплой `.github/workflows/deploy.yml` (push в main → test → build → Pages). `npm test` — настройки/параллакс.
- Арт: `art_src/layers nightcity/` (не менять). `python3 tools/make_layers.py` → `public/layers/*.png` (storm 1671→1672) и маски `public/layers/masks/<слой>_fx.png` (r тёплые окна, g фаза кластера 6x6, b неон — по порогам цвета). PSD не коммитим.
- Порядок: небо → облака (дрейф, зеркальный повтор без шва) → far → midfar → midnear → near → дождь (3 слоя, как rainroom) → room. Холст 1672x941 1:1, CSS contain + pixelated.
- Параллакс `src/config.js` LAYERS (sky 4 … near 34 px × сила), слои увеличены на 3–5 % под запас; комната 2 px. Выкл: сенсор, `?q=low`, `?nofx=parallax`.
- Небо: dusk/night/day/storm (storm = storm_sky + storm_clouds + редкие молнии). Настройки `nightcity.settings.v1`.
- Отладка: `?sky=`, `?rain=0..1`, `?nofx=rain,clouds,city,lightning,parallax`, `window.__nightcity`.
- Скриншоты: `npx vite preview --port 4190 &` и `node tools/shots.mjs http://localhost:4190/nightcity/ shots/v1`.
- Меню — порт из rainroom (☰ справа внизу, hud.glass, автозакрытие 5 с, стрелки/Enter — пульт, 1–4 небо, M звук, F экран, колесо — дождь). Скриншот: `node tools/menushot.mjs <url> shots/v2/menu.png`.
- Важно (three r170): не класть меши в Group с renderOrder — группа сортируется после всех слоёв (облака оказались поверх комнаты).
- Маски (v3): связные компоненты (scipy, `.venv/bin/python tools/make_layers.py`), закрытие 3x3, мин. площадь 6/8 px; g = id компоненты → окно гаснет целиком (редко, плавно, период 25–45 с), неон пульсирует всей полосой, глитч редкий и слабый. Смещения параллакса округляются до целых px. Проверка: `node tools/seqshots.mjs <url> shots/v3`.
- В однострочном коде не вставлять `//` посреди строки — закомментирует остаток (сборка падала).
- Лампы (v4): `LAMPS` в `src/config.js` (координаты в room.png, зоны клика). `.venv/bin/python tools/make_light.py` → `masks/room_nrm.png` (rg псевдонормаль из собеля яркости, b блеск) и `masks/room_emit.png` (r лампа, g панель). Шейдер комнаты: диффуз + блики (квантованы), ореол и отражение в стекле на прозрачных пикселях, плавное вкл/выкл ~0.3 с. Кнопки «Лампа»/«Панель», клик по светильнику, клавиши L/K. `?lamps=left,right|all|none`; `?q=low` — без нормалей и бликов. Скриншоты: `node tools/lampshots.mjs <url> shots/v4`.
- Свет v5 (как в rainroom — запечённый ON−OFF): `.venv/bin/python tools/bake_light.py [--preview]` → `masks/lit_left.png`, `lit_right.png` — аддитивные тёплые карты (диффуз по нормалям, общая тёплая засветка, блики, ручные маски бликов на предметах `OBJ` — ноутбук, кружка, радио, шкатулка, книги, камера; тёплое пятно и отражения на подоконнике). Шейдер: room + I·lit. Правая панель ×1.5. Превью без браузера: /tmp/bake_both.png.
- Звёзды (v6): `.venv/bin/python tools/make_stars.py` → `masks/stars_night.png` (r звезда, g id; в сумерках звёзд нет — 0). Мерцают только в «Ночь», выкл `?nofx=stars` и `?q=low`. Проверка: `node tools/starshots.mjs <url> shots/v6`.
- Переходы неба (v7): `src/transition.js` — веса пресетов, smoothstep ~10 с, переключение посреди перехода от текущей смеси; параметры пресетов (огни, звёзды, цветокоррекция города/комнаты, гроза, добавка дождя) в PRESET_PARAMS. Все 4 неба и оба набора облаков загружены и смешиваются; молнии при весе грозы > 0.85. При загрузке — сразу. `?tt=сек`. Скриншоты: `node tools/transshots.mjs <url> shots/v7`.
- Радио (v8, как в rainroom): `src/radio.js` (Tuner из rainroom без изменений), помехи/свип в `Ambience` (radioOut → master, общая громкость и M глушат и радио). Станции: `node tools/merge_stations.mjs stations_in/*.json` → `public/stations.json` (https, без HLS, без дублей). Зона `RADIO` в `src/config.js` (hit, dial, led в пикселях room.png). Вкл: клик по радио, кнопка «Радио», R; N — следующая станция; колесо над включённым радио — станции; ‹ › и громкость в меню. Вкл — тёплая шкала, зелёный индикатор, hover — подсветка. Настройки radio/radioVol/radioStation в `nightcity.settings.v1`. `?radio=1`. Скриншоты: `node tools/radioshots.mjs <url> shots/v8`.
- Виды города (v9): **параллакс выключен** (`PARALLAX_ENABLED = false` в `src/config.js`; код, `layerOffset`, `?nofx=parallax` сохранены; ползунок закомментирован в `index.html` — вернуть: флаг true + раскомментировать). Раскладки слоёв — **одно место**: `CITY_LAYOUTS` в `src/config.js` (`x`, `y` — сдвиг центра слоя в px холста 1672x941, +y вниз; `scale` — масштаб PNG). `panorama` (по умолчанию, из `art_src/nightcity_panorama.psd`), `classic` (старый вид, не удалять). Новый вид = новый ключ — сам появится в меню. Меню: строка ‹ Панорама › (плавно ~1.2 с), стрелки клавиатуры виды НЕ переключают. `?city=classic`, настройка `city` в `nightcity.settings.v1`. Маски огней едут вместе со слоем (тот же меш).
- Быстро сменить фон: подвинуть слои в Photoshop в PSD 1890x1063 (порядок слоёв: Background, небо, Layer 2 far, 3 midfar, 4 midnear, 5 near; PNG-исходники не менять) → `.venv/bin/python tools/psd_layout.py art_src/<файл>.psd <имя>` → вставить напечатанную строку в `CITY_LAYOUTS`. Проверка: `node tools/cityshots.mjs <url> shots/v9`. Неравномерное растяжение в PSD не поддерживается (только масштаб+сдвиг).
